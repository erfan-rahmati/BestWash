# راهنمای نسخه نهایی BestWash

راهنمای جامع نصب، مهاجرت، تنظیم SMS.ir و اعلان لحظه‌ای، اجرای توسعه و سناریوهای تست نسخه نهایی در فایل زیر قرار دارد:

- [`ADMIN_CONSOLE_V2_FA.md`](./ADMIN_CONSOLE_V2_FA.md)
- [`CUSTOMER_WEBAPP_COMPLETION_FA.md`](./CUSTOMER_WEBAPP_COMPLETION_FA.md)

نکات حیاتی این نسخه:

- برنامه مشتری همچنان وب‌اپلیکیشن موبایل‌محور است.
- پنل مدیریت به‌طور کامل فارسی، واکنش‌گرا و فرم‌محور بازطراحی شده است.
- ورود مدیر فقط با نام کاربری و رمز عبور آغاز می‌شود و مرحله دوم پیامک اجباری است.
- شماره موبایل مدیر در رابط عمومی پنل قابل تغییر نیست.
- پرداخت طبق درخواست پروژه روی `zarinpal` و `ZARINPAL_SANDBOX=true` باقی مانده است.
- پس از نصب وابستگی‌ها، حتماً `pnpm --filter api db:generate` و سپس `prisma migrate deploy` اجرا شود.
