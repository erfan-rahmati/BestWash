## حفاظت‌های سمت سرور

- تغییر ساعت یا تعطیلی روز با رزرو قطعی یا مهلت پرداخت فعال متداخل پذیرفته نمی‌شود.
- محدودیت نیم‌ساعته در API ایجاد رزرو نیز دوباره کنترل می‌شود و تنها یک محدودیت ظاهری نیست.
- رد رزرو و بازپرداخت، صدور و مصرف کد تحویل و تغییر وضعیت‌ها تراکنشی و دارای لاگ ممیزی هستند.
- شماره موبایل احراز هویت مدیر از پنل عمومی قابل تغییر نیست؛ ورود شامل نام کاربری، رمز عبور و کد پیامکی مرحله دوم است.
- بارگذاری رسانه با کنترل نوع، امضای فایل، اندازه، نام امن و Header جلوگیری از MIME sniffing انجام می‌شود.
- کلید خصوصی Push و کلیدهای SMS.ir فقط از متغیر محیطی Worker خوانده می‌شوند.

راهنمای نصب، کلیدهای موردنیاز و سناریوهای تست در `docs/ADMIN_CONSOLE_V2_FA.md` قرار دارد.
