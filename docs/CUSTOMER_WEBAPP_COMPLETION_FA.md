# تکمیل اصلاحیه وب‌اپلیکیشن مشتری BestWash

این نسخه، اصلاحیه وب‌اپلیکیشن مشتری را در ۱۷ فاز تکمیل می‌کند و ظاهر موبایل‌محور برنامه و نسخه نهایی پنل مدیریت را حفظ می‌کند.

## فازهای انجام‌شده

1. همگام‌سازی کمپین‌ها، محتوای عمومی و وفاداری با پنل مدیریت
2. نمایش استاندارد پلاک ملی در جزئیات رزرو
3. بازطراحی مودال فاکتور به‌صورت پنل پایین استاندارد
4. چاپ اختصاصی و تمیز فاکتور رسمی
5. رنگ‌بندی معنایی وضعیت رزروها
6. بازطراحی ویرایش خودرو و امکان ویرایش پلاک ملی
7. حذف نمایش تکراری و خام پلاک در کارت خودرو
8. تثبیت سطح دستی باشگاه و افزودن تاریخچه جزئی امتیازها
9. اصلاح هدیه پرداخت موفق و نمایش کوچک پلاک ملی
10. بازطراحی صفحه تماس و اتصال کامل آن به پنل مدیریت
11. اصلاح مودال ذخیره خودرو در فرایند رزرو
12. بازطراحی صفحه درباره ما و اتصال آن به پنل مدیریت
13. بازطراحی صفحه قوانین و اتصال آن به پنل مدیریت
14. افزودن نقشه Google Maps به صفحه پشتیبانی
15. نمایش عمودی کارت‌های مقالات
16. توسعه فوتر، جایگاه اینماد و اصلاح امضای توسعه‌دهنده
17. یکپارچه‌سازی نمایش و ورود پلاک ملی در برنامه مشتری و پنل مدیریت مرتبط

## مهاجرت پایگاه داده

مهاجرت جدید زیر باید پس از تهیه نسخه پشتیبان اجرا شود:

```text
20260823120000_customer_webapp_completion
```

این مهاجرت دو قابلیت اصلی را اضافه می‌کند:

- قفل سطح باشگاه در صورت تعیین دستی مدیر، برای جلوگیری از بازنشانی ناخواسته
- ثبت تحویل هر پیشنهاد تخفیف به هر مشتری و رزرو، برای جلوگیری از نمایش تکراری

## اجرای به‌روزرسانی در PowerShell

```powershell
Set-Location "C:\Users\ERFAN\Desktop\bestwash"

docker compose -f docker/compose.dev.yml up -d
pnpm install --frozen-lockfile
pnpm --filter api db:generate
pnpm --filter api exec prisma migrate deploy
pnpm --filter api db:seed
```

سپس API، Worker و Web را در سه ترمینال جدا اجرا کنید:

```powershell
pnpm --filter api dev
pnpm --filter worker dev
pnpm --filter web dev
```

## تنظیم محتوای صفحات عمومی

از پنل مدیریت، بخش «اسلایدر و بنر» و سپس «صفحات اطلاعاتی و فوتر» قابل کنترل است. در این بخش می‌توان محتوای درباره ما، تماس با ما، قوانین، نشانی، لینک نقشه، ساعات کاری و لینک‌های اینماد را بدون ویرایش کد تغییر داد.

برای نقشه، لینک نمایش باید یک نشانی امن Google Maps با پروتکل HTTPS باشد. تا پیش از دریافت اینماد، جایگاه استاندارد نماد در فوتر نمایش داده می‌شود.

## کنترل کیفیت این نسخه

```powershell
pnpm --filter api exec prisma validate
pnpm --filter api typecheck
pnpm --filter api test
pnpm --filter api build

pnpm --filter worker typecheck
pnpm --filter worker test
pnpm --filter worker build

pnpm --filter web lint
pnpm --filter web typecheck
pnpm --filter web build
```

درگاه پرداخت همچنان زرین‌پال و در محیط توسعه روی Sandbox باقی مانده است.
