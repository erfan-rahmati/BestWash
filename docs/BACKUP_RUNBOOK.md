# Runbook پشتیبان‌گیری

## پشتیبان روزانه

```bash
docker compose -f docker/compose.prod.yml exec -T postgres pg_dump -Fc -U bestwash bestwash > bestwash-$(date +%F).dump
```

فایل را رمزنگاری و خارج از سرور اصلی نگهداری کنید. نگهداری پیشنهادی: ۷ نسخه روزانه، ۴ نسخه هفتگی و ۱۲ نسخه ماهانه. حداقل ماهی یک‌بار Restore آزمایشی انجام دهید.

## بازیابی

1. ترافیک نوشتن را متوقف کنید.
2. Image و Schema مورد انتظار نسخه پشتیبان را مشخص کنید.
3. دیتابیس خالی بسازید و `pg_restore --clean --if-exists` اجرا کنید.
4. API و Worker را بالا بیاورید و سلامت، ورود، فهرست رزرو و یک پرداخت آزمایشی را بررسی کنید.
5. زمان، دلیل و نتیجه بازیابی را در گزارش حادثه ثبت کنید.
